## About

I'm a Communication and Collaboration Administrator with nearly 10 years in IT. I manage ~2,000 users across 2 separate hybrid Microsoft 365 tenants.

**My day-to-day work includes:**

- Managing identities, groups, and access in Azure Entra ID and on-premises Active Directory
- Administering Exchange Online and Exchange Server on-premises across both tenants
- Administering SharePoint and Teams across both tenants
- Writing PowerShell scripts for bulk changes, repetitive tasks, and data gathering
- Tracking down the cause of mail flow, calling, and permission problems
- Maintaining ~500 Windows servers, Hyper-V virtual hosts, and virtual machines

**Migrations** are some of my most involved work. I've completed more than 8 email and tenant migrations to Microsoft 365. Each one requires knowing what exists, moving it in the right order, and making sure everything works after.

If you're planning a move to Microsoft 365, running a hybrid environment, or managing more than one tenant, I'd be glad to compare notes. Send me a message.
